# 主要功能

```text
功能入口
├─ Mod：Minecraft 服务端内的在线功能
│  ├─ 在线快照备份
│  │  ├─ 按玩家在线时长定时备份；可配置服务器启动和关闭时备份
│  │  ├─ 支持手动触发备份
│  │  ├─ 备份前强制保存世界并暂时关闭自动保存，完成后恢复保存状态
│  │  └─ 配置排除规则、压缩级别、处理资源预算和快照留存策略
│  ├─ 快照管理
│  │  ├─ 查看快照列表及空间信息、当前或最近任务状态
│  │  ├─ 查看单个快照详情
│  │  └─ 删除快照
│  ├─ 在线区块回档
│  │  ├─ 将指定维度、指定快照中的区块回档到游戏中
│  │  ├─ 可使用最新快照
│  │  └─ 目标区块必须已加载，并处理该区块关联的实体数据
│  └─ 历史区块预览
│     ├─ 临时查看指定快照中的区块状态
│     ├─ 汇报方块、方块实体和实体的差异，不直接改写世界
│     └─ 结束预览并恢复客户端视图
├─ CLI：独立命令行工具，无需运行 Minecraft 服务端
│  ├─ 在线快照仓库管理
│  │  ├─ 列出和删除快照
│  │  ├─ 将快照导出为世界文件，可选择 ZIP 打包和输出路径
│  │  └─ 将指定快照的单个区块回档到离线世界目录
│  └─ 归档管理
│     ├─ 从在线快照生成完整包或差分包
│     ├─ 列出和校验归档
│     ├─ 将完整包或完整包与差分包组合恢复为世界文件
│     └─ 将归档中的完整与差分快照导入在线仓库
└─ TUI：通过交互菜单执行备份管理操作
   ├─ 在线快照
   │  ├─ 查看快照
   │  ├─ 导出世界文件，可选择 ZIP 和输出目录
   │  ├─ 删除快照
   │  └─ 创建完整归档或差分归档
   ├─ 归档
   │  ├─ 将完整包或完整包与差分包组合恢复为世界文件
   │  ├─ 将归档导入在线仓库
   │  └─ 校验完整包或完整包与差分包的组合
   └─ 启动参数指定在线仓库根目录和归档根目录
      ├─ 未显式传入时使用工作目录
      ├─ 创建完整或差分归档写入归档根目录
      └─ 归档导入写入在线仓库根目录
```

## 数据形态

| 形态 | 载体 | 位置 |
| --- | --- | --- |
| 游戏存档 | Minecraft save 目录：`level.dat`、`region/`、`entities/`、`data/` 等 | 任意目录，不要求在备份根内 |
| 快照 | 在线仓库的 `index.db` 清单与 `blobs/` 内容 blob | CLI 用 `--snapshot-root`，TUI 用启动参数，默认工作目录 |
| 归档 | 归档根下的 tar | CLI 用 `--archive-root`，TUI 用启动参数，默认工作目录 |

| 归档类型 | 文件名 | 基线 |
| --- | --- | --- |
| 完整归档 | `S-x[full].tar` | 无 |
| 差分归档 | `S-base[S-target].tar` | 创建时由 `--base` 指定的在线快照 |

快照与归档共用内容身份：Region 以 `contentHash`、普通文件以 `sourceHash` 寻址。游戏存档是解压后的 MCA 与普通文件，没有内容身份，进出游戏存档时重新计算哈希。

## 转换路径

本节描述当前实现已存在的转换路径，入口以 CLI 分发与 TUI 菜单为准；归档读写细节见[快照到归档](流程/快照到归档.md)与[归档到快照](流程/归档到快照.md)。

| 方向 | CLI | TUI | Mod | 产物 |
| --- | --- | --- | --- | --- |
| 游戏存档 → 快照 | `snapshot create` | 菜单 5 | `/foldbackup backup` | 在线快照 |
| 游戏存档 → 归档 | 无 | 无 | 无 | — |
| 快照 → 游戏存档 | `snapshot export` | 菜单 2 | 无 | save 目录或 ZIP |
| 快照 → 游戏存档（单区块） | `snapshot rollback` | 无 | `/foldbackup rollback chunk` | 就地写回目标区块 |
| 快照 → 归档 | `archive create` | 菜单 4 | 无 | 完整归档或差分归档 |
| 归档 → 快照 | `snapshot import --all-archive` | 菜单 7 | 无 | 在线快照 |
| 归档 → 游戏存档 | `archive export` | 菜单 6 | 无 | save 目录 |

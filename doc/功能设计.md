# 主要功能

```text
功能入口
├─ Mod：Minecraft 服务端内的在线功能
│  ├─ 在线快照备份
│  │  ├─ 按玩家在线时长定时备份；可配置服务器启动和关闭时备份
│  │  ├─ 支持手动触发备份
│  │  ├─ 备份前强制保存世界并暂时关闭自动保存，完成后恢复保存状态
│  │  └─ 配置排除规则、压缩级别、处理资源预算和快照留存策略
│  ├─ 快照管理
│  │  ├─ 查看快照列表及空间信息、当前或最近任务状态
│  │  ├─ 查看单个快照详情
│  │  └─ 删除快照
│  ├─ 在线区块回档
│  │  ├─ 将指定维度、指定快照中的区块回档到游戏中
│  │  ├─ 可使用最新快照
│  │  └─ 目标区块必须已加载，并处理该区块关联的实体数据
│  └─ 历史区块预览
│     ├─ 临时查看指定快照中的区块状态
│     ├─ 汇报方块、方块实体和实体的差异，不直接改写世界
│     └─ 结束预览并恢复客户端视图
├─ CLI：独立命令行工具，无需运行 Minecraft 服务端
│  ├─ 在线快照仓库管理
│  │  ├─ 列出和删除快照
│  │  ├─ 将快照导出为世界文件，可选择 ZIP 打包和输出路径
│  │  └─ 将指定快照的单个区块回档到离线世界目录
│  └─ 归档管理
│     ├─ 从在线快照生成完整包或差分包
│     ├─ 列出和校验归档
│     ├─ 将完整包或完整包与差分包组合恢复为世界文件
│     └─ 将归档中的完整与差分快照导入在线仓库
└─ TUI：通过交互菜单执行备份管理操作
   ├─ 在线快照
   │  ├─ 查看快照
   │  ├─ 导出世界文件，可选择 ZIP 和输出目录
   │  ├─ 删除快照
   │  └─ 创建完整归档或差分归档
   ├─ 归档
   │  ├─ 将完整包或完整包与差分包组合恢复为世界文件
   │  ├─ 将归档导入在线仓库
   │  └─ 校验完整包或完整包与差分包的组合
   └─ 启动参数指定已存在的在线仓库根目录和/或归档根目录；至少指定一个
      ├─ 未指定归档根目录时，归档恢复、导入和校验功能不开放
      ├─ 创建完整或差分归档时，未指定归档根目录则将归档写入在线仓库根目录
      └─ 导入优先写入在线仓库根目录；未提供时写入归档根目录
```

# 快照到游戏存档流程

本文定义把在线备份库中的快照恢复为 Minecraft 游戏存档目录的流程，也可以称为回档。

## 1. 输入与产物

| 项 | 内容 |
| --- | --- |
| 输入 | 在线仓库 `index.db` 中的快照记录，以及 `blobs/` 中按内容身份寻址的 Region 与普通文件 blob |
| 产物 | 目标目录下的游戏存档：世界元数据、区域文件、实体区域、数据文件等 |
| 在线仓库 | 只读：不写入 `index.db` 与 `blobs/` |
| 目标目录 | 不存在时自动创建（含缺失的父目录）；存在时如果能识别为游戏存档，就地更新 |
| 临时空间 | 不使用全局暂存：目录写入在目标同目录使用单文件临时文件，ZIP 导出在目标同目录使用暂存目录 |

Region 以区域内容身份寻址，普通文件以文件内容身份寻址，与备份、归档共用同一套身份。

## 2. 入口

| 入口 | 形式 |
| --- | --- |
| CLI | `foldbackup snapshot export` |
| TUI | 快照库 → 导出为游戏存档 |

两个入口共用同一套检查、写入、删除与统计实现。选项、默认值与互斥见[CLI 命令设计方案](../CLI命令设计方案.md)，菜单步骤、提示与默认路径见[TUI 设计方案](../TUI设计方案.md)。

执行顺序固定为：目标检查与锁 → 检查阶段 → 统计与决策 → 写入 → 删除。统计必须在决策之前产出，用户先看到会删除什么，再决定是否删除。

## 3. 目标目录检查与锁

```text
确定目标目录
├─ 解析快照 ID
│  └─ 非法或不存在: 报错
├─ 参数检查（与磁盘状态无关）
│  └─ 输出路径为空白或没有文件/目录名: 报错
├─ 目标目录存在:
│  ├─ 不是目录: 报错
│  ├─ 非空且缺 level.dat: 报错
│  ├─ 是空目录: 视为新建，不取锁
│  └─ 是游戏存档: 取世界锁，成功后进入检查
│     └─ 无法取得: 终止
└─ 目标目录不存在: 视为新建，写入阶段创建目录，不取锁
```

创建只发生在写入阶段：检查阶段与只检查不执行的预览都不创建任何目录，因此预览一个不存在的目标不会留下痕迹。父路径不可创建（父路径是文件或没有权限）时报错。

游戏存档识别排在取锁之前，因为锁会在目标目录创建 `session.lock`，先取锁会让“空目录”与“游戏存档”的判定失真。锁一直持有到写入与删除结束，保证检查与执行看到同一个世界状态。

## 4. 检查阶段

检查阶段不改动快照条目与用户文件（除了锁文件 `session.lock`），因此取消不产生副作用。

检查对两个入口都是必做阶段，两个入口的差异只在如何呈现检查结果，见[CLI 命令设计方案](../CLI命令设计方案.md)与[TUI 设计方案](../TUI设计方案.md)。

判定复用[在线备份设计方案](../在线备份设计方案.md)第 2、3 节定义的元数据比较与内容身份计算：先比源元数据，未变化即视为相同；否则计算内容身份，与快照记录比较。与备份的差异如下：

| 项 | 备份 | 恢复 |
| --- | --- | --- |
| 比较对象 | 当前世界与最新快照记录 | 目标存档与被恢复快照的记录 |
| 文件标识 | 参与比较 | 不比较 |
| Blob 存在性 | 快速命中的前提 | 不参与判定 |
| 读取异常 | 扫描错误，备份失败 | 视为不同，走恢复 |
| 命中后的动作 | 复用已有 Blob | 跳过写入 |

不比较文件标识，是因为恢复写入会改变文件标识，比较它会让下一次回档必然失配。

目标目录的遍历是恢复独有的，用来得到删除候选：

```text
检查目标目录
├─ 不在快照条目中的普通文件: 加入删除候选(需要排除session.lock)
├─ 不在快照条目中的 .mca: 加入区域单元删除候选，连同其范围内的 .mcc
└─ .mcc 不单独成为候选，只随区域单元处理
```

## 5. 统计

| 组 | 内容 |
| --- | --- |
| 更改 | 待写入的区域与文件数量 |
| 跳过 | 元数据命中的区域与文件、内容身份命中的区域与文件 |
| 删除 | 总数、按后缀分组的数量（无扩展名单列）、会被完全删除的目录 |

目录被完全删除指该目录下没有保留的文件，且其子目录也都被完全删除；统计只列每个被清空子树的最外层目录，删除时由内向外逐层移除。

统计在检查阶段结束后、删除开始前产出，是否删除由用户看过统计后决定。删除组始终产出；未选择连带删除时它只表示目标中将被保留的条目。

只检查不执行的预览输出与执行完全相同的统计，不写入、不删除，但仍然取得世界锁，保证与随后的执行看到同一个世界状态。

## 6. 写入

```text
写入每个待写入条目
├─ 普通文件
│  ├─ 从 blob 解压，边写边计算内容身份，写入同目录临时文件
│  ├─ 大小与内容身份一致: 改名覆盖目标
│  └─ 不一致: 删除临时文件并报错
└─ 区域
   ├─ 解码 LRH 帧，逐块校验并累加区域内容身份
   ├─ 重建 .mca（zlib），超过 255 扇区的区块写入 .mcc
   ├─ 内容身份一致: 原子改名落地
   ├─ 删除本次写入未生成的 .mcc
   └─ 不一致: 删除临时文件并报错

写入完成后
└─ 把修改时间设为源元数据中与条目同路径文件的源时间
   ├─ 区域取 .mca 的记录，本次生成的 .mcc 沿用同一时间
   └─ 取不到记录时保留写入时间
```

被跳过的条目不读取、不移动、不重写，修改时间保持原样。

region 文件按整体替换：写入一个区域时，该单元内本次未重新生成的 `.mcc` 一律清除，与是否开启连带删除无关。

写入逐条落地，不暂存整份世界：中途失败时已落地的条目保留，不回滚，目标可能处于部分更新状态；失败条目丢弃自己的临时文件。

## 7. 删除

删除只在显式选择连带删除时执行，并且排在全部写入与校验之后。

```text
连带删除
├─ 区域单元: 删除不在快照中的 .mca 及其范围内的 .mcc
├─ 普通文件: 删除不在快照条目中的路径
└─ 顺序: 先完成全部写入与校验，再删除
```

未开启时目标中不在快照里的内容全部保留。删除中途失败不回滚已删除的内容，但因为排在写入之后，不会造成内容缺失。删除完成后，统计中列为会被完全删除的目录一并移除；此时仍有其他文件留下的目录保持原样。

## 8. ZIP 变体

`snapshot export --zip` 与 TUI 的 ZIP 导出使用同一套写入流程，产物是单个 ZIP 文件：

```text
ZIP 导出
├─ 在目标 ZIP 同目录创建暂存目录
├─ 以暂存目录为目标执行第 4–6 节的写入
│  └─ 目标始终是新建的空目录：没有可比较、可跳过、可删除的内容，也不取世界锁
├─ 打包暂存目录：条目名为相对路径，沿用已恢复的修改时间
├─ 原子替换目标 ZIP
└─ 删除暂存目录

不变量
├─ 不输出统计，不提供连带删除与只检查不执行功能选项
├─ 目标已存在同名 ZIP 时整份替换，没有目录导出的覆盖与就地更新语义
└─ 中途失败时保留原目标 ZIP，暂存目录与半成品 ZIP 一并清理
```

缺少 `.zip` 时自动补全，因此同一份快照写出 `world-export/<快照名称>.zip` 的默认路径。

# TUI 设计方案

## 目标

- 快照库根目录、归档库根目录只由启动参数提供。
- TUI 只展示目录状态和执行操作，不管理根目录配置。
- 编号菜单使用 `0` 返回或退出；从存档创建快照的路径输入使用空行返回。

## 启动状态

启动后分别显示两个根目录的状态；未传入对应目录时显示未启用。两个根目录都启用时示例：

```text
快照库：已启用  <snapshot-root>
归档库：已启用  <archive-root>
```

未传入 `--snapshot-root` 时，快照功能不开放。
未传入 `--archive-root` 时，归档功能不开放。

## 主菜单

```text
快照库
  1. 查看快照
  2. 导出为游戏存档
  3. 删除快照
  4. 创建归档
  5. 从游戏存档创建快照

归档库
  6. 导出为游戏存档
  7. 全部导入快照库
  8. 校验归档

  0. 退出
```

## 路径规则

- 根目录：固定使用启动参数。
- 从游戏存档创建快照：源路径必须输入，指向游戏存档根目录；目标固定为启用的快照库根目录。快照库应放在存档之外，当前不检查源目录与快照库的重叠关系。
- 快照导出和归档导出的默认存档目录共用 `world-export/<快照名称>`，该路径为最终目录，不再追加快照名或归档名子目录。
- 快照导出为 ZIP 时，默认路径为 `world-export/<快照名称>.zip`；输入路径为最终 ZIP 文件路径，必须使用 `.zip` 扩展名。ZIP 包根目录直接包含存档内容。
- 默认路径同时允许用户输入其他路径；直接回车使用默认路径，输入 `0` 返回。
- 传入 `--archive-root` 时，归档默认写入 `--archive-root`。
- 未传入 `--archive-root` 时，归档默认写入 `--snapshot-root`。
- 传入 `--snapshot-root` 时全部导入快照库默认写入 `--snapshot-root`。
- 未传入 `--snapshot-root` 时全部导入快照库默认写入 `--archive-root`。

## 已有输出目标

- 快照导出和归档导出的最终输出路径已存在时拒绝执行，不合并目录或覆盖文件；用户需选择新的输出路径。
- 创建归档时遇到同名归档拒绝覆盖。
- 从游戏存档创建快照时，目标快照库可以是新目录或已有库；向已有库追加快照，保留历史快照。同秒快照身份冲突时拒绝本次备份，不重试或覆盖。

## 交互规则

- 菜单：`0` 返回或退出。
- 确认：`1` 确认，`2` 取消，`0` 返回。
- 路径：回车使用默认值，`0` 返回。
- 线程数：回车使用自动值，正整数指定线程数，`0` 返回上一步；非法值原地重试。

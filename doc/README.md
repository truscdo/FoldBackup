# 文档约定

本目录下所有文档必须经过人工审核和修改，作为项目实现基准，当实际代码与文档有差异时以本目录下文档为准。

## 文档制图

- 流程图使用 `text` 代码块和 `├─`、`└─`、`│` 树形图，不用 Mermaid
- 带缩进的换行表示从属关系
- 无缩进的换行表示顺序，在此基础上带有`:`表示条件，例如 `条件A:`、`条件B:`
- 不同的树形图可以表示并行关系或子流程
- 每级缩进使用 3 个空格

```text

流程A
├─ 顺序工序1
│  ├─ 条件A: 继续顺序执行
│  └─ 条件B: 发送给流程B处理
├─ 顺序工序2
└─ 顺序工序3

流程B
├─ 顺序工序1
└─ 顺序工序2

```
